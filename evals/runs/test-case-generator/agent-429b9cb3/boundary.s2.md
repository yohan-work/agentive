## 먼저 확인이 필요한 부분

**모순/모호한 점**
- "쿠폰은 중복 사용 가능"과 "한 주문에 하나만 쓸 수 있어요"가 충돌할 수 있습니다. "중복 사용"이 ① 같은 쿠폰을 **여러 주문에 반복 사용**할 수 있다는 뜻인지, ② **한 주문에 여러 쿠폰을 겹쳐 쓴다**는 뜻인지에 따라 결과가 정반대입니다. ②라면 "한 주문에 하나만"과 정면으로 모순됩니다.
- 최대 할인 금액은 기획서 확인 후 전달 예정이라 값이 없습니다. 해당 케이스는 기대 결과 대신 "확인할 내용"으로 적었습니다.

**질문 (중요도 순)**
1. "중복 사용 가능"은 같은 쿠폰을 여러 주문에서 재사용 가능하다는 뜻인가요? 그렇다면 사용 횟수 제한(1인당/전체)이 있나요?
2. 최대 할인 금액(상한)은 정률 쿠폰에만 적용되나요, 정액 쿠폰에도 적용되나요? 쿠폰마다 다른가요, 전역 값인가요?
3. 할인 금액이 주문 금액보다 크면 어떻게 처리하나요(0원 결제 허용 / 적용 불가 / 배송비 포함 여부)? 원 단위 이하 금액은 반올림·올림·버림 중 무엇인가요?

아래는 명확한 부분에 대한 잠정 케이스입니다. 가정은 [ASSUMPTION]으로 표시했습니다.

## 2. 커버리지 노트

**다룬 것**
- 할인 유형: 정액, 정률 각각의 기본 적용
- "한 주문에 하나만": UI 추가 적용 시도, 교체, 서버 우회 요청
- "중복 사용 가능": 여러 주문 재사용(가정), 횟수 제한 여부
- 최대 할인: 초과 / 정확히 같음 / 1원 미만 경계, 정액 적용 여부 — 값이 없어 모두 "확인할 내용"으로 작성
- 경계값: 주문 금액보다 큰 정액, 같은 정액, 100% 정률, 소수점 금액
- 상태: 적용, 해제, 장바구니 변경 후 재계산, 새로고침·이탈 후 유지, 결제 실패, 주문 취소
- 회귀 위험: 할인 재계산 누락, 금액 음수, 화면 간 금액 불일치, 동시 사용

**일부러 뺀 것**
- 질문 1이 ②(한 주문에 여러 장 겹쳐 쓰기)로 답이 오면 CP-03~05, CP-06은 다시 써야 합니다.
- 최대 할인 금액이 확정되면 CP-08~11의 기대 결과를 구체 금액으로 바꿔드리겠습니다.
- 단위 테스트 후보는 도구가 정해지지 않아 확정하지 않았습니다.

**Also consider** (요청에 없는 동작, 확인 후 필요하면 확장)
- 쿠폰 유효기간 만료 쿠폰 적용 시도 시 거부되는지
- 최소 주문 금액 조건이 있다면 그 미만 금액에서 적용 불가인지
- 특정 상품/카테고리 한정 쿠폰이면 대상 외 상품 할인 제외되는지
- 배송비가 할인 대상에 포함되는지
- 쿠폰 코드 직접 입력 방식이면 잘못된 코드·대소문자·공백 처리
- 비로그인 사용자의 쿠폰 사용 가능 여부
- 쿠폰과 포인트/적립금 동시 사용 시 계산 순서
- 부분 취소·부분 환불 시 할인액 안분
- 모바일/PC에서 쿠폰 선택 UI 동작 동일 여부
