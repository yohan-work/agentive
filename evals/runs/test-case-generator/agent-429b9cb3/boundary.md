## 먼저 확인이 필요한 부분

**상충되는 요구사항**
- "쿠폰은 중복 사용 가능"과 "한 주문에 하나만 쓸 수 있어요"가 충돌할 수 있습니다. "중복 사용"이 ① 같은 쿠폰을 **여러 주문에 반복 사용** 가능하다는 뜻인지, ② 한 주문에 **여러 쿠폰을 겹쳐 쓰는(스태킹)** 것인지에 따라 정반대가 됩니다. 아래 케이스는 ①로 해석했습니다.

**질문 (중요한 순서)**
1. "중복 사용 가능"은 같은 쿠폰을 여러 주문에 다시 쓸 수 있다는 뜻인가요? 그렇다면 사용자당/전체 사용 횟수 제한이 있나요?
2. 최대 할인 금액은 정률·정액 모두에 적용되나요, 정률에만 적용되나요? (금액은 기획서 확인 후 주신다고 하셨으니, 해당 케이스는 값 자리만 비워 두었습니다.)
3. 할인 금액이 주문 금액보다 클 때(정액 쿠폰), 결제 금액은 0원 처리인가요, 쿠폰 적용 불가인가요? 그리고 할인 기준 금액은 상품 금액만인가요, 배송비 포함인가요?

테스트 도구(단위 테스트 프레임워크 등)를 알려주시지 않아서 "단위 테스트 후보" 열은 **후보 여부만** 표시했습니다. 도구와 대상 모듈을 알려주시면 대상 함수까지 지정해 드리겠습니다.

## 2. 커버리지 노트

**다룬 것**
- 할인 유형: 정률(CP-01, 07), 정액(CP-02, 08, 09)
- 최대 할인 금액: 초과·정확히 같음·1원 미만 경계(CP-03~05), 정액 적용 여부(CP-06) — 기획서 값 받으면 금액만 채우면 됩니다
- 경계값: 주문 금액과 같거나 큰 정액(CP-08, 09), 소수점 절사(CP-07), 0 할인(CP-19)
- "한 주문에 하나": 추가 적용 차단, 교체, 해제(CP-10~12)
- "중복 사용": 재사용, 쿠폰함 상태, 동시 사용, 취소 시 처리(CP-13~16)
- 상태 유지/회귀: 새로고침(CP-17), 장바구니 변경 재계산(CP-18), 서버 측 금액 검증(CP-20)

**의도적으로 뺀 것 (요청에 없는 동작)**
- 최소 주문 금액 조건은 언급이 없어 제외했습니다.
- 질문 1~3 답변에 따라 CP-06, 08, 10, 13~16의 기대 결과가 확정됩니다.

**Also consider**
- 쿠폰 유효기간 만료/시작 전 쿠폰 적용 차단
- 특정 상품·카테고리 한정 쿠폰
- 최소 주문 금액 조건
- 쿠폰 코드 직접 입력 (잘못된 코드, 대소문자, 공백)
- 부분 환불 시 할인 금액 배분
- 배송비에 할인 적용 여부
- 비로그인 사용자 쿠폰 적용
- 모바일/PC 화면에서 할인 금액 표시 일관성

최대 할인 금액을 주시면 CP-03~06에 실제 금액과 경계 주문 금액을 채워서 바로 돌려드리겠습니다.
