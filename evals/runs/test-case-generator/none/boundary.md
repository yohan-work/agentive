쿠폰 기능 테스트 케이스 정리해 드립니다. 먼저 확인이 필요한 부분 두 가지를 짚고 갈게요.

## 먼저 확인할 점

1. **"중복 사용 가능"의 의미**: 아래에서는 **"같은 쿠폰을 여러 주문에 반복해서 사용할 수 있다"**로 해석했습니다. (한 주문에 여러 쿠폰을 겹쳐 쓰는 것은 "한 주문에 하나만"과 충돌하므로 제외) 혹시 사용 횟수 제한(예: 1인당 N회, 전체 N회)이 있다면 알려주세요.
2. **최대 할인 금액**: 기획서 확인 전이라 `{MAX}`로 표기했습니다. 값이 정해지면 해당 케이스의 기대 결과만 채우시면 됩니다.

그 외 기획서에서 같이 확인하시면 좋을 항목: 최소 주문 금액 조건, 유효기간, 할인 계산 기준(상품가 vs 배송비 포함), 원 단위 절사/반올림 규칙, 주문 취소 시 쿠폰 복원 여부.
