오늘 중으로 쓰실 수 있게 바로 정리했습니다. 먼저 확인이 필요한 부분 두 가지를 짚고, 그 가정 위에서 테스트 케이스를 드릴게요.

## 먼저 확인할 점

1. **"중복 사용 가능"의 의미**
   "한 주문에 하나만"과 함께 쓰셔서 **"같은 쿠폰을 여러 주문에 반복 사용할 수 있다"(재사용 가능)**로 해석했습니다.
   만약 "다른 할인(프로모션, 적립금 등)과 중복 적용 가능"이라는 뜻이라면 아래 D 섹션을 그 기준으로 바꿔야 합니다.
2. **최대 할인 금액**
   기획서 값이 아직 없어 `MAX`로 표기했습니다. 값을 받으면 경계값 케이스(C-05 ~ C-08)에 숫자만 채우시면 됩니다.
   정액 쿠폰에도 MAX가 적용되는지(보통은 정률에만 적용)도 함께 확인해 주세요.

## 우선순위 제안 (오늘 시간이 부족하다면)

1. **C-01 ~ C-08, C-12**: 금액이 틀리면 바로 매출 손실이나 CS로 이어집니다.
2. **B-01 ~ B-03**: "한 주문에 하나" 규칙이 서버에서 지켜지는지.
3. **D-01, D-04**: 재사용과 동시 결제.
4. **E-01 ~ E-03**: 결제 실패와 취소 시 금액.

## 정책 확인이 필요한 항목 모음

- "중복 사용"의 정확한 의미(재사용 vs 다른 할인과 중복)
- 최대 할인 금액 `MAX` 값, 정액 쿠폰에도 적용되는지
- 정률 할인 소수점 처리(반올림/올림/절사)
- 할인 기준 금액에 배송비 포함 여부
- 정액 할인이 주문 금액보다 클 때 처리
- 두 번째 쿠폰 선택 시 차단인지 교체인지
- 재사용 횟수 제한 유무
- 최소 주문 금액 조건 유무(있다면 경계값 케이스 추가 필요)
- 취소/부분 취소 시 쿠폰 복원과 할인 안분 규칙

MAX 값을 알려주시면 C 섹션을 실제 숫자로 채워서 바로 실행 가능한 형태로 다시 드릴게요.
