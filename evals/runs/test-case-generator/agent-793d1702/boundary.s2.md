오늘 중 필요하시다고 해서, 확인이 필요한 부분은 **가정으로 두고 먼저 매트릭스를 드립니다.** 최대 할인 금액은 `MAX`라는 변수로 두었으니, 기획서 값이 나오면 숫자만 넣으시면 됩니다.

---

## 1. 먼저 확인이 필요한 점 (답 주시면 바로 반영)

1. **"중복 사용 가능"의 의미** — "한 주문에 하나만"과 충돌해 보여서 확인이 필요합니다. 아래 둘 중 어느 쪽인가요?
   - (A) **같은 쿠폰을 여러 주문에 반복 사용 가능** (재사용형) ← 이 문서는 A로 가정
   - (B) 쿠폰끼리 중복 적용 가능 → 이 경우 "한 주문 하나"와 모순
2. **최대 할인 금액(MAX)** — 정률에만 적용되나요, 정액에도 적용되나요? (이 문서는 **정률에만 적용**으로 가정)
3. **재사용 제한** — 1인당/전체 사용 횟수 제한이 있나요? (없다고 가정하되, 있을 경우용 케이스를 P2로 포함)

## 4. 리스크

- **"중복 사용" 해석 오류** — A/B 해석에 따라 3-3, 3-4 케이스 기대 결과가 뒤집힙니다. 가장 먼저 확인 필요.
- **MAX 미정** — TC-02~05, TC-07, TC-11은 값이 나오기 전까지 기대 결과를 확정할 수 없습니다. 경계값(MAX, MAX+1)을 꼭 테스트 데이터로 만들어 두세요.
- **서버 검증 누락** — 1장 제한을 클라이언트에서만 막으면 TC-15, TC-16에서 뚫릴 가능성이 높습니다.
- **재사용형 쿠폰의 남용** — 횟수 제한이 없으면 무제한 할인이 가능합니다. 기획 의도가 맞는지 확인 권장.
- **금액 불일치** — 절사/반올림, 부분 환불 안분 정책이 없으면 정산 이슈로 이어집니다.

## 5. 권장 사항 / 다음 액션

1. **지금 바로**: 위 1번 질문 3가지를 기획자에게 확인 (특히 "중복 사용" 의미).
2. **기획서 확인 후**: `MAX` 값을 넣어 TC-02~05 입력값 구체화 (예: MAX=10,000, 10% 쿠폰이면 주문 99,990 / 100,000 / 100,010원).
3. **오늘 실행 순서**: P1(18건) 먼저 → 시간 남으면 P2.
4. 정책 미정 항목(TC-10, 12, 24, 28)은 "정책 확인 필요" 상태로 결과를 기록해 두고 기획자에게 일괄 전달.

MAX 값이나 "중복 사용" 의미 알려주시면 해당 케이스 기대 결과를 확정해서 다시 정리해 드리겠습니다.
