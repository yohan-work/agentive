SOP 초안을 만들기 전에 먼저 한 가지 짚고 가야 할 부분이 있습니다. 두 번째 요청(상담원이 법 조항 번호를 들어 환불을 거절하는 부분)은 **그대로 SOP에 넣으면 오히려 회사에 불리할 가능성이 큽니다.** 이유를 먼저 설명드리고, 그걸 반영한 SOP를 드릴게요.

---

## 먼저 확인할 점: "14일 경과 = 환불 불가"가 법적으로 통하지 않을 수 있습니다

제가 변호사는 아니고 조항은 개정될 수 있어서, 아래 내용은 **법무 검토 전 참고용**으로 봐 주세요. 다만 방향 자체는 꽤 분명합니다.

1. **전자상거래법의 청약철회 예외는 "거절 근거"로 쓰기 어렵습니다.**
   - 전자상거래법 제17조 제2항 제5호에 "디지털콘텐츠 제공이 개시된 경우 청약철회 제한"이 있기는 합니다. 하지만
     - 가분적(나눠 쓸 수 있는) 콘텐츠는 **제공이 시작되지 않은 부분은 철회가 가능**하다는 단서가 붙어 있고,
     - 같은 조 제6항에 따라 사업자가 이 제한 사실을 **미리 명확히 표시하는 등 조치를 하지 않았다면 제한 자체가 적용되지 않습니다.**
   - 게다가 이 조항은 "청약철회(계약을 없던 일로 하는 것)"에 관한 것이지, 계약 **중도 해지**까지 막아 주는 조항이 아닙니다.

2. **구독은 "계속거래"라서 중도 해지·잔여분 환급 문제가 따로 걸립니다.**
   - 방문판매법상 계속거래(1개월 이상 계속 공급) 규정은 소비자의 계약 해지권과 과도한 위약금 금지를 두고 있고(제31조, 제32조 부근),
   - 공정위 고시인 **소비자분쟁해결기준**에도 온라인 콘텐츠/강의 이용 계약 중도 해지 시 "이용분 + 위약금(통상 잔여 금액의 10% 수준) 공제 후 환급" 같은 기준이 있습니다.
   - 특히 **연간 구독(290,000원)**을 결제 한 달 후 해지 요청하는 고객에게 "14일 지났으니 전액 환불 불가"로 답하면, 소비자원 분쟁조정이나 공정위 민원에서 사업자가 질 가능성이 높습니다.

3. **약관규제법 리스크**
   - 소비자에게 부당하게 불리한 해지·환불 제한 약관은 무효가 될 수 있고(약관규제법 제6조, 제9조 등), 전자상거래법 제35조도 소비자에게 불리한 특약을 무효로 봅니다. "약관에 써 있다"가 최종 방어가 되지 않을 수 있습니다.

4. **상담원이 조항 번호로 안내하는 방식 자체의 위험**
   - 상담원이 잘못된 조항을 인용하거나 해석을 단정하면, 그 상담 기록이 그대로 분쟁 증거가 됩니다.
   - "법적으로 거절할 수 있다"는 안내는 법무/책임자 단에서만 하도록 하는 게 일반적입니다.

**그래서 제안:** SOP에는 "법 조항으로 거절하는 스크립트" 대신, ① 월/연 구독별 표준 처리 기준, ② 상담원이 단정하지 않는 안내 문구, ③ 법적 주장·분쟁 언급 시 에스컬레이션 경로를 넣는 게 안전합니다. 아래 SOP는 그렇게 구성했고, **숫자(위약금 비율, 재량 한도 등)는 법무 검토 후 확정할 자리**로 표시해 두었습니다.

# SOP: 결제 후 14일 경과 고객의 환불 요청 처리

| 항목 | 내용 |
|---|---|
| 문서 번호 | CS-REF-002 (가칭) |
| 적용 대상 | CS팀 상담원 전원, CS 리드 |
| 적용 범위 | 결제일로부터 14일이 지난 뒤 들어온 환불·해지 요청 (월 구독 29,000원 / 연 구독 290,000원) |
| 목적 | 상담원별 대응 편차 제거, 법적 분쟁 리스크 최소화, 처리 기록 일원화 |
| 승인 필요 | 법무(또는 외부 자문) 검토 후 시행 — **[ ] 표시 항목은 확정 전 사용 금지** |

## 1. 기본 원칙

1. 상담원은 **법 조항을 근거로 환불 가능/불가를 단정하지 않는다.** 판단 근거는 이 SOP의 기준표뿐이다.
2. "환불 불가"라는 표현 대신 **"이 SOP 기준에 따른 처리 결과"**를 안내한다.
3. 모든 건은 동일한 템플릿으로 티켓에 기록한다 (6항 참조).
4. 고객이 법·소비자원·공정위·소송을 언급하면 **즉시 에스컬레이션**한다 (5항).

## 2. 접수 시 확인 항목 (체크리스트)

- [ ] 구독 유형: 월 / 연
- [ ] 결제일, 요청일, 경과 일수
- [ ] 수강 진도율(%) 및 마지막 수강일
- [ ] 결제 수단 (카드 / 간편결제 / 계좌이체 등)
- [ ] 자동 갱신으로 인한 결제인지 여부 (갱신 사전 고지 발송 기록 포함)
- [ ] 요청 사유: 단순 변심 / 서비스 장애·품질 불만 / 중복·오결제 / 갱신 인지 못함 / 기타
- [ ] 과거 환불·예외 처리 이력
- [ ] 고객이 법률·기관(소비자원, 공정위 등)을 언급했는지

## 3. 처리 기준표

### 3-1. 사유와 무관하게 우선 적용 (전액 환불 또는 즉시 에스컬레이션)

| 상황 | 처리 |
|---|---|
| 중복 결제·오결제 | 해당 결제 전액 환불 (기간 무관) |
| 회사 측 서비스 장애로 상당 기간 이용 불가 | 전액 또는 이용 불가 기간 비례 환불 → CS 리드 승인 |
| 자동 갱신 결제인데 사전 고지 기록이 없거나 불명확 | CS 리드 에스컬레이션 (전액 환불 검토) |
| 결제 후 수강 이력 0% | CS 리드 승인 하에 전액 환불 검토 **[법무 확인 필요]** |

### 3-2. 월 구독 (29,000원)

| 조건 | 처리 |
|---|---|
| 14일 경과, 단순 변심 | 당월 환불 없이 **다음 결제일부터 자동 갱신 해지** 처리 안내. 당월 말까지 이용 가능 |
| 14일 경과, 품질 불만 등 사유 있음 | 해지 + 재량 보상(예: 부분 환불 또는 크레딧) 가능 — 상담원 재량 한도 **[ ]원** |

### 3-3. 연 구독 (290,000원) — 가장 분쟁이 많은 구간

| 조건 | 처리 |
|---|---|
| 14일 경과 후 해지 요청 | **중도 해지 + 잔여분 환급** 산식 적용 (아래) |

**환급 산식(안) — 법무 확정 전 초안**

```
환급액 = 결제금액 − 이용분 − 위약금
이용분  = 이용 개월 수 × [월 정가 29,000원 또는 월 환산가 24,167원 중 법무 확정 기준]
위약금  = 잔여 금액의 [10%]  (소비자분쟁해결기준 수준을 넘지 않도록)
```

예시 (월 정가 기준으로 이용분 계산 시, 결제 후 2개월 이용):
- 이용분 58,000원, 잔여 232,000원, 위약금 23,200원 → 환급 208,800원

※ 이용분을 "월 정가"로 차감할지 "연 할인 환산가"로 차감할지는 약관 명시 여부와 분쟁 리스크에 따라 달라지므로 **반드시 법무가 한 가지로 확정**해 주세요.

## 4. 상담 스크립트

**4-1. 월 구독, 단순 변심**
> 문의 주셔서 감사합니다. 확인해 보니 결제일로부터 14일이 지나 약관상 이번 달 결제분은 전액 환불 대상에 해당하지 않습니다. 대신 지금 자동 갱신을 해지해 드리면 다음 결제부터는 청구되지 않고, 이번 달 ○월 ○일까지는 그대로 수강하실 수 있습니다. 해지 진행해 드릴까요?

**4-2. 연 구독, 중도 해지**
> 연간 이용권은 결제 후 14일이 지나 전액 환불 기간은 지났지만, 중도 해지 시 이용하신 기간과 위약금을 제외한 잔여 금액을 환급해 드리고 있습니다. 고객님의 경우 예상 환급액은 ○○○원이며, 산정 내역을 함께 보내 드리겠습니다.

**4-3. 고객이 "법적으로 환불받을 권리가 있다"고 주장할 때**
> 말씀 주신 부분은 제가 이 자리에서 법적으로 판단해 드리기 어려워, 담당 부서에서 정확히 검토한 뒤 ○영업일 이내에 회신드리겠습니다.

**사용 금지 표현**
- "법적으로 환불 의무가 없습니다" / "전자상거래법 제○조에 따라 거절됩니다"
- "소비자원에 신고하셔도 소용없습니다"
- "약관에 동의하셨으니 어쩔 수 없습니다" (단독 사용 금지)

## 5. 에스컬레이션

| 트리거 | 담당 | 목표 응답 |
|---|---|---|
| 재량 한도 초과 보상 요청 | CS 리드 | 1영업일 |
| 법 조항·소비자원·공정위·소송 언급 | CS 리드 → 법무 | 2영업일 내 1차 회신 |
| 자동 갱신 고지 누락 의심 | CS 리드 | 1영업일 |
| 동일 고객 2회 이상 예외 요청 | CS 리드 | 1영업일 |
| SNS·커뮤니티 공개 게시 언급 | CS 리드 + 마케팅/PR | 당일 |

## 7. 운영·개선

- 월 1회 CS 리드가 해당 건(월 약 40건)을 사유·처리 결과별로 집계
- 반복 사유(예: 자동 갱신 인지 못함)가 많으면 **갱신 사전 알림, 결제 페이지 환불 규정 고지**를 개선 — 이게 문의 자체를 줄이는 가장 효과적인 방법입니다
- 법령·고시 개정 시 법무가 SOP 3항·4항 재검토

## 시행 전에 법무 쪽에 확인받을 것

1. 우리 콘텐츠가 전자상거래법 제17조 제2항 제5호의 청약철회 제한 대상인지, 그리고 제6항의 표시 의무를 결제 화면·약관에서 충족하고 있는지
2. 연 구독 중도 해지 시 이용분 산정 기준(월 정가 vs 할인 환산가)과 위약금 비율
3. 현행 약관의 "14일 경과 후 환불 불가" 문구가 약관규제법상 유효한지, 문구 수정이 필요한지
4. 상담원 재량 보상 한도

원하시면 법무 검토용으로 위 질문들을 정리한 한 장짜리 메모나, 약관 환불 조항 수정안 초안도 만들어 드릴게요.
