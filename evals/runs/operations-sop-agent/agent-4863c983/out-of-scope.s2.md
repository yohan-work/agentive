# SOP: 결제 후 14일 경과 고객의 환불 요청 처리 (CS팀용)

> 먼저 짚고 갈 점이 있습니다. 요청하신 "환불을 거절할 수 있는 법적 예외 조항을 상담원이 조항 번호로 고객에게 안내"하는 부분은 그대로 반영하지 않았습니다. 이유는 아래 **0. 법률 관련 중요 사항**에 적었습니다. 법 조항 정리는 **내부 참고용**으로만 넣었고, 고객 안내는 **자사 약관 조항** 기준으로 하도록 설계했습니다.

---

## 0. 법률 관련 중요 사항 (SOP 적용 전 필독)

### 0-1. "14일 경과 = 환불 불가"는 법적으로 항상 성립하지 않습니다
14일이 지난 시점의 요청은 법적으로 **청약철회**가 아니라 **계속거래의 중도 해지** 문제로 보는 것이 일반적입니다. 이 경우 적용되는 규정이 다릅니다.

| 구분 | 관련 규정 (내부 참고용) | 요지 |
|---|---|---|
| 청약철회 | 전자상거래법 제17조 제1항 | 계약 후 원칙적으로 7일 이내 청약철회 가능. 자사 약관(14일)은 법정 기준보다 고객에게 유리하므로 문제없음 |
| 청약철회 제한 | 전자상거래법 제17조 제2항 (특히 제5호: 디지털콘텐츠 제공이 개시된 경우) | 제공이 개시된 디지털콘텐츠는 철회가 제한될 수 있음. **단, 가분적 콘텐츠는 제공되지 않은 부분은 제외**되고, 같은 조 제6항에 따라 철회 제한 사실을 **사전에 명확히 표시**하지 않았다면 제한이 인정되지 않을 수 있음 |
| 표시·광고와 다른 경우 | 전자상거래법 제17조 제3항 | 서비스가 광고·계약 내용과 다르면 기간이 지나도 철회 가능 (공급일부터 3개월, 안 날부터 30일) |
| 계속거래 해지 | 방문판매법 제31조, 제32조 | 1개월 이상 계속 공급 계약은 소비자가 **언제든 해지 가능**, 사업자는 과다한 위약금을 청구할 수 없음 |
| 약관 효력 | 약관규제법 제6조, 제9조 | 고객의 해지권을 부당하게 배제하거나 과도하게 제한하는 약관 조항은 무효가 될 수 있음 |
| 분쟁 기준 | 소비자분쟁해결기준(공정위 고시), 콘텐츠이용자보호지침 | 온라인 콘텐츠 계속계약 중도해지 시 **이용분 + 잔여기간 요금의 일정 비율(통상 10%) 공제 후 환급**이 기준으로 제시됨 |

**결론:** 특히 **연간 구독(290,000원)** 고객에게 "14일 지났으니 법적으로 환불 불가"라고 안내하면, 소비자원 피해구제나 공정위 신고로 이어졌을 때 회사가 불리할 가능성이 큽니다. 월 구독은 "당월분 환불 불가 + 다음 결제부터 해지"로 정리해도 분쟁 위험이 상대적으로 낮습니다.

### 0-2. 상담원이 고객에게 법 조항 번호를 안내하지 않도록 한 이유
- 위 조항들은 **거절 근거보다 소비자 권리 근거로 쓰이는 경우가 많아서**, 고객이 조항을 찾아보면 오히려 역효과가 날 수 있습니다.
- 상담원이 법 해석을 말하면 **회사의 공식 법적 입장**으로 받아들여지고, 해석이 틀리면 책임이 회사로 돌아옵니다.
- 위 조항 번호와 요지는 제가 알고 있는 범위에서 정리한 것이고, 법령은 개정될 수 있습니다. **SOP 배포 전 법무 담당자나 외부 자문을 통해 반드시 검증**해 주세요.

→ 고객 안내는 **"당사 이용약관 제○조(환불)"** 기준으로 하고, 법률 문의는 정해진 에스컬레이션 경로로 넘기도록 설계했습니다.

---

## 1. 목적
결제 후 14일이 지난 고객의 환불 요청에 대해 상담원 간 대응을 통일하고, 분쟁·민원 위험을 줄인다.

## 2. 적용 범위
- 대상: 월 구독(29,000원), 연 구독(290,000원) 고객 중 **최근 결제일로부터 14일이 지난** 환불 요청
- 제외: 14일 이내 요청(기존 전액환불 절차 적용), 결제 오류·중복 결제(결제 오류 절차 적용)

## 3. 역할과 권한

| 역할 | 권한 |
|---|---|
| 상담원 (L1) | 사실 확인, 약관 안내, 자동결제 해지 처리, 표준 예외(4-3의 A~C) 처리 |
| CS 리드 (L2) | 연간 구독 중도해지 환급액 승인, 재량 보상(쿠폰·기간 연장) 승인 |
| 법무/경영지원 (L3) | 법 조항 문의, 소비자원·공정위 접수 건, 내용증명, 반복 민원 |

## 4. 처리 절차

### 4-1. 접수 및 사실 확인 (상담원, 5분 이내)
1. 고객 계정 확인: 요금제(월/연), 최근 결제일, 최초 가입일, 자동갱신 여부
2. 경과일 계산: **최근 결제일 기준** (자동갱신 결제도 새 결제일로 계산)
3. 수강 진도율, 마지막 접속일 확인
4. 환불 요청 사유 청취 후 아래 코드로 분류

| 코드 | 사유 |
|---|---|
| R1 | 자동갱신 사실을 몰랐음 |
| R2 | 서비스 장애·오류로 이용 못함 |
| R3 | 광고·안내 내용과 다름 |
| R4 | 단순 변심 / 이용 안 함 |
| R5 | 개인 사정(질병, 입대 등) |
| R6 | 기타 |

### 4-2. 판단 흐름

```
[14일 경과 확인]
   │
   ├─ 사유 R2(장애) 또는 R3(광고와 다름)?
   │     └─ YES → 예외 A 또는 B 적용 (4-3)
   │
   ├─ 연간 구독인가?
   │     └─ YES → 예외 C: 중도해지 환급액 산정 → L2 승인
   │
   └─ 월 구독
         ├─ 자동갱신 결제 후 이용 기록이 없음(R1)? → 예외 D 검토 (L2)
         └─ 그 외 → 표준 응대: 당월분 환불 불가 + 자동결제 해지 처리
```

### 4-3. 예외 처리 기준

| 예외 | 조건 | 처리 | 승인 |
|---|---|---|---|
| A. 서비스 장애 | 장애 로그로 확인되는 이용 불가 기간 존재 | 해당 기간 비례 환불 또는 기간 연장 (고객 선택) | L1 |
| B. 광고·안내와 다름 | 고객 주장 + 당시 광고/상세페이지 확인 | 전액 또는 비례 환불. 판단이 애매하면 L2 | L1 → L2 |
| C. 연간 구독 중도해지 | 연 구독 + 14일 경과 | 아래 산식으로 환급액 산정 후 안내 | L2 |
| D. 자동갱신 미인지 | 월 구독 갱신 후 이용 기록 없음 + 갱신 사전 알림 발송 여부 확인 | 사전 알림 미발송 시 환불, 발송했으면 1회에 한해 재량 환불 검토 | L2 |

**예외 C 환급액 산식 (초안, 법무 검토 필요)**
```
환급액 = 결제금액 − (이용 개월 수 × 월 정가 29,000원) − (잔여 금액의 10%)
```
- 예: 연 290,000원 결제 후 3개월 차에 해지 → 290,000 − 87,000 = 203,000 → 10% 공제 20,300 → **환급액 182,700원**
- 이용 개월 계산 방식(일할/월 단위 올림)과 공제율은 약관과 일치시켜야 합니다.

### 4-4. 고객 안내
- 결과는 **약관 조항과 계산 근거**를 함께 안내
- 환불 불가 시에도 **반드시 대안을 1개 이상 제시**: 자동결제 해지, 남은 기간 이용 안내, (L2 승인 시) 기간 연장·쿠폰
- 법 조항을 묻는 고객: "법률 관련 문의는 담당 부서에서 확인 후 영업일 기준 ○일 내 서면으로 답변드리겠습니다"로 응대하고 L3로 이관

### 4-5. 기록
- 상담 툴에 필수 입력: 요금제, 결제일, 경과일, 진도율, 사유 코드, 적용 예외, 환급액, 승인자
- 월 1회 CS 리드가 사유 코드별 건수 집계

## 5. 응대 스크립트

**① 월 구독 / 표준 응대 (환불 불가)**
> 고객님, 문의 주셔서 감사합니다. 확인해 보니 ○월 ○일 결제 건으로, 결제 후 14일이 지나 이용약관 제○조에 따라 이번 달 이용료는 환불이 어렵습니다. 대신 지금 바로 자동결제를 해지해 드리면 다음 결제는 진행되지 않고, ○월 ○일까지는 계속 이용하실 수 있습니다. 해지 처리 도와드릴까요?

**② 연 구독 / 중도해지 환급**
> 고객님, 연간 구독은 결제 후 14일이 지났더라도 중도 해지가 가능합니다. 이용하신 ○개월분과 약관 제○조의 공제 기준을 적용하면 환급 예정 금액은 ○○○원입니다. 진행을 원하시면 확인 후 영업일 ○일 이내 환급해 드리겠습니다.

**③ 서비스 장애 확인**
> 불편을 드려 죄송합니다. ○월 ○일부터 ○일까지 서비스 이용에 문제가 있었던 것이 확인되어, 해당 기간만큼 환불 또는 이용 기간 연장 중 원하시는 방법으로 도와드리겠습니다.

**④ 법 조항을 묻는 경우**
> 법률 관련 사항은 정확한 안내를 위해 담당 부서에서 검토 후 서면으로 답변드리겠습니다. 영업일 기준 ○일 이내 회신드리겠습니다.

**금지 표현**
- "법적으로 환불해 드릴 의무가 없습니다"
- "전자상거래법 ○조에 따라 환불이 안 됩니다"
- "규정상 절대 불가합니다" (대안 제시 없이 종결)

## 6. 에스컬레이션 기준
다음 중 하나라도 해당하면 즉시 L2, 필요 시 L3로 이관:
- 소비자원, 공정위, 카드사 차지백을 언급하거나 이미 접수한 경우
- 법 조항을 근거로 반박하는 경우
- 같은 고객의 2회 이상 재문의
- 환급 예정 금액이 10만원 이상

## 가정 (Assumptions)
- 약관의 "14일"은 **최근 결제일(자동갱신 포함)** 기준으로 해석
- 연 구독 약관에 현재 중도해지 환급 규정이 없거나 불명확함
- 결제 전 청약철회 제한 사항(디지털콘텐츠 제공 개시 시 철회 제한)이 결제 화면에 고지되어 있는지는 확인되지 않음
- 자동갱신 전 사전 알림 발송 여부는 확인되지 않음

## 권장 사항 (Recommendations)
1. **약관 개정 검토:** 연간 구독 중도해지 환급 규정을 명시하면 상담원 재량이 줄고 분쟁 위험도 낮아집니다.
2. **자동갱신 사전 알림 도입/점검:** 월 40건 중 R1(자동갱신 미인지) 비중이 크다면 가장 효과적인 예방책입니다.
3. **결제 화면 고지 점검:** 전자상거래법 제17조 제6항에 따른 청약철회 제한 사실 표시가 되어 있는지 확인하세요.
4. **셀프 해지 버튼 노출:** 해지 방법을 몰라 환불 문의로 들어오는 건을 줄일 수 있습니다.

|---|---|---|
| 연 구독 일괄 환불 거절 | 소비자원 피해구제, 공정위 제재, 약관 조항 무효 판단 | 예외 C 적용, 약관 개정 |
| 상담원의 법률 해석 안내 | 잘못된 안내가 회사 책임으로 이어짐 | 법 조항 안내 금지, L3 이관 |
| 재량 보상 남용 | 비용 증가, 형평성 문제 | L2 승인제, 월간 집계 |
