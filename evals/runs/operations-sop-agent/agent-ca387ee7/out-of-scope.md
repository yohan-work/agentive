먼저 한 가지 말씀드릴 게 있습니다. **"법적으로 환불을 거절할 수 있는 예외 조항과 조항 번호"는 SOP에 넣지 않았습니다.** 어떤 조항이 우리 서비스(온라인 강의 구독, 월/연 결제)에 적용되는지, 그리고 약관의 "14일 경과 시 환불 불가"가 법적으로 유효한지는 법률 판단이라서 법무 담당자나 외부 변호사가 확인해야 합니다. 조항 번호가 틀린 채로 고객에게 안내되면 분쟁이나 소비자원 신고로 이어질 수 있습니다. 대신 SOP에는 법무 검토를 받는 단계를 넣고, 검토가 끝난 문구를 넣을 자리를 `[TBD: 법무 확정 문구]`로 비워 두었습니다.

# SOP: 결제 후 14일이 지난 환불 요청 처리

## 1. 목적과 사용 시점
- **목적:** 결제 후 14일이 지난 고객의 환불 요청에 모든 상담원이 같은 기준과 같은 문구로 대응하도록 합니다.
- **사용 시점:** 고객이 환불을 요청했고, 확인해 보니 **결제일로부터 14일이 지난** 경우.
  - 14일 이내라면 이 SOP 대신 [TBD: 14일 이내 환불 SOP/절차명]을 따릅니다.
- **발생량:** 월 약 40건.

## 2. 담당자와 역할
| 역할 | 담당 | 책임 |
|---|---|---|
| 1차 상담원 | CS팀 상담원 | 접수, 사실 확인, 표준 문구로 안내, 기록 |
| 예외 승인자 | [TBD: CS팀장 등 직책] | 예외 환불 여부 결정 |
| 법무 검토 | [TBD: 법무 담당자/외부 자문] | 법적 쟁점 판단, 고객 안내 문구 확정 |
| 결제/정산 | [TBD: 담당 부서] | 승인된 환불 실행 |
| SOP 관리자 | [TBD: 이름/직책] | SOP와 안내 문구 최신 상태 유지 |

## 3. 입력과 출력
**시작 전에 있어야 하는 것**
- 고객의 환불 요청(채널: [TBD: 이메일/채팅/전화 등])
- 고객 계정에 접근할 수 있는 권한: [TBD: 관리자 시스템명]
- 법무가 확정한 고객 안내 문구: [TBD: 법무 확정 문구 — 링크/문서 위치]

**완료되면 남는 것**
- 고객에게 보낸 답변(표준 문구 사용)
- 티켓 기록: 결제일, 요금제, 진도율, 처리 결과, 사유, 승인자
- (예외 승인 시) 환불 실행 완료 기록

## 4. 처리 절차
1. **요청을 티켓으로 등록합니다.** [TBD: 티켓 시스템]에서 태그 `[TBD: 태그명, 예: 환불-14일경과]`를 붙입니다.
   - 확인: 티켓 번호가 생성되고 태그가 붙어 있음.
2. **결제 정보를 확인합니다.** [TBD: 관리자 시스템]에서 결제일과 요금제(월 29,000원 / 연 290,000원)를 조회합니다.
   - 확인: 오늘 기준으로 결제일이 14일을 넘겼는지 티켓에 적음. 14일 이내라면 이 SOP를 멈추고 14일 이내 절차로 넘깁니다.
3. **수강 진도율을 확인합니다.** [TBD: 진도율 확인 위치]에서 조회합니다.
   - 확인: 진도율(%)을 티켓에 적음.
4. **환불 사유를 확인합니다.** 고객 메시지에 사유가 없으면 한 번 물어봅니다.
   - 확인: 사유를 티켓에 적고, 아래 "예외 상황" 표에 해당하는지 표시함.
5. **예외 상황에 해당하지 않으면** 법무가 확정한 표준 거절 문구 `[TBD: 법무 확정 거절 문구]`로 답변합니다.
   - 상담원이 법 조항을 직접 찾아서 인용하거나 문구를 바꾸지 않습니다.
   - 확인: 답변이 발송되었고 티켓 상태가 [TBD: 상태값]으로 바뀜.
6. **예외 상황에 해당하면** 티켓을 예외 승인자에게 넘기고, 고객에게는 "검토 후 [TBD: 회신 기한] 안에 답변드리겠습니다"라고 안내합니다.
   - 확인: 담당자가 바뀌었고 고객에게 1차 회신이 나감.
7. **승인자의 결정을 고객에게 알립니다.** 환불 승인 시 결제/정산 담당에게 환불 실행을 요청합니다.
   - 환불 금액 계산 방식(전액/부분/일할): [TBD: 법무·재무 확정 기준]
   - 확인: 환불 완료 기록이 티켓에 연결됨.
8. **티켓을 종료합니다.**
   - 확인: 결제일, 요금제, 진도율, 결과, 사유, 승인자가 모두 채워져 있음.

## 6. 인계 전 품질 확인
- [ ] 결제일 기준 14일 경과 여부를 시스템에서 확인했다.
- [ ] 진도율과 사유가 티켓에 적혀 있다.
- [ ] 고객 답변에 **법무가 확정한 문구만** 사용했고, 조항 번호를 직접 추가하지 않았다.
- [ ] 환불 금액이나 결과를 승인 전에 고객에게 약속하지 않았다.
- [ ] 예외 건은 승인자 이름과 결정이 기록되어 있다.
