# SOP: 결제 후 14일 경과 고객의 환불 요청 처리

> **먼저 확인할 점 (법적 조항 안내 관련)**
> 요청하신 "환불을 거절해도 되는 전자상거래법·소비자보호법상 예외 조항 번호"는 이 SOP에 직접 적지 않았습니다. 어떤 조항이 우리 서비스(온라인 강의 구독)에 적용되는지, 그리고 14일이 지난 경우 환불을 전부 거절할 수 있는지, 아니면 남은 기간을 계산해 일부 환불해야 하는지는 법적 판단이라 법무 담당자(또는 외부 자문)가 확정해야 합니다. 틀린 조항 번호를 고객에게 안내하면 분쟁이 생기거나 소비자원·공정위 민원으로 이어질 수 있습니다.
> 그래서 SOP에는 **법무가 승인한 안내 문구를 받아 넣는 자리**([TBD: 법무 승인 안내 문구])를 두었고, 승인되기 전까지 상담원은 조항 번호를 말하지 않도록 했습니다.

---

## 1. 목적과 적용 시점
- **목적:** 결제 후 14일이 지난 고객이 환불을 요청할 때 모든 상담원이 같은 기준과 같은 문구로 대응하게 한다. (현재 월 약 40건 접수)
- **적용 시점:** 고객이 환불을 요청했고, 결제일로부터 14일이 지난 경우.
  - 14일 이내라면 이 SOP가 아니라 [TBD: 14일 이내 환불 절차 문서명]을 따른다.

## 2. 담당자와 역할
| 역할 | 담당 | 책임 |
|---|---|---|
| 1차 상담원 | CS팀 상담원 | 요청 접수, 사실 확인, 표준 문구로 안내, 기록 |
| 예외 승인자 | [TBD: CS팀장 또는 지정자] | 예외 환불 여부 결정 |
| 법무 검토 | [TBD: 법무 담당자/외부 자문] | 법적 쟁점이 있는 건 판단, 안내 문구 승인 |
| SOP 관리자 | [TBD: SOP 관리 담당자] | 문구와 기준 변경 시 SOP 업데이트 |

## 3. 입력과 결과
**시작 전에 있어야 하는 것**
- 고객의 환불 요청 (채널: [TBD: 이메일/채팅/전화 등])
- 고객 계정 정보 (가입 이메일 또는 회원 ID)
- 결제 내역 조회 권한 ([TBD: 결제 관리 시스템명])
- 수강 진도 조회 권한 ([TBD: 강의 관리자 페이지명])
- 법무가 승인한 안내 문구 ([TBD: 법무 승인 안내 문구], 승인 전에는 4.6단계의 임시 문구 사용)

**완료되면 나오는 것**
- 고객에게 보낸 답변 (환불 불가 안내, 예외 환불 처리, 또는 법무 검토 중이라는 안내)
- [TBD: CS 티켓 시스템명]에 기록된 처리 결과와 사유 태그

## 4. 절차

1. **요청 접수:** [TBD: CS 티켓 시스템명]에서 티켓을 열고 태그 `환불-14일경과`를 붙인다.
   - 확인: 티켓에 태그가 붙어 있다.

2. **고객 확인:** 가입 이메일/회원 ID로 계정을 찾는다.
   - 확인: 티켓의 고객 정보와 계정 정보가 일치한다. 일치하지 않으면 고객에게 결제 이메일을 다시 요청한다.

3. **결제 정보 확인:** [TBD: 결제 관리 시스템명]에서 요금제(월 29,000원 / 연 290,000원)와 결제일을 확인하고 티켓에 적는다.
   - 확인: 결제일부터 오늘까지 경과 일수를 계산해 적었다.
   - 14일 이내로 나오면 이 SOP를 멈추고 14일 이내 환불 절차로 넘긴다.

4. **수강 진도 확인:** [TBD: 강의 관리자 페이지명]에서 수강 진도(%)를 확인하고 티켓에 적는다.
   - 확인: 진도 % 값이 티켓에 기록되어 있다.

5. **예외 상황 확인:** 고객 메시지와 계정 기록을 5번 표(예외 처리)와 대조한다.
   - 해당하는 항목이 있으면 표의 지시를 따르고 이 절차의 6단계는 건너뛴다.
   - 확인: 티켓에 "예외 해당 없음" 또는 해당 예외 항목명을 적었다.

6. **고객 안내 (예외 없음):** 표준 문구로 답변한다.
   - 법무 승인 문구가 있으면: [TBD: 법무 승인 안내 문구]를 그대로 사용한다.
   - 승인 전 임시 문구: "이용약관상 전액 환불은 결제 후 14일 이내이면서 수강 진도 10% 미만일 때 가능합니다. 고객님은 결제 후 [N]일이 지나 약관상 환불 대상이 아닙니다." ([TBD: 임시 문구 사용 여부 법무 확인])
   - **법 조항 번호는 법무 승인 문구에 들어 있을 때만 안내한다.** 상담원이 직접 조항을 찾거나 해석해서 말하지 않는다.
   - 확인: 답변이 발송되었고, 사용한 문구 버전이 티켓에 기록되어 있다.

7. **재요청 대응:** 고객이 다시 이의를 제기하면 같은 문구를 반복하지 말고, 예외 표에 해당하는지 다시 확인한 뒤 예외 승인자에게 넘긴다.
   - 확인: 티켓 담당자가 예외 승인자로 바뀌었다.

8. **종료 기록:** 처리 결과(환불 불가 / 예외 환불 / 법무 검토)와 사유 태그를 선택하고 티켓을 닫는다.
   - 확인: 결과 필드와 사유 태그가 비어 있지 않다.

## 5. 예외 처리
| 상황 | 할 일 | 에스컬레이션 대상 |
|---|---|---|
| 고객이 법 조항, 소비자원, 공정위, 소송 등을 언급 | 답변하지 말고 "담당 부서 확인 후 [TBD: 회신 기한] 안에 답변드리겠다"고만 안내 | 법무 담당자 ([TBD]) |
| 고객이 "서비스 장애로 강의를 못 들었다"고 주장 | 장애 기록 확인을 요청하고 결론은 내지 않음 | [TBD: 기술팀 담당자] 확인 후 예외 승인자 |
| 중복 결제 또는 결제 오류로 보임 | 결제 관리 시스템에서 중복 여부 확인 후 기록 | [TBD: 결제/정산 담당자] |
| 고객이 해지(자동결제 중단)만 원하는지 환불을 원하는지 불분명 | 둘 중 무엇을 원하는지 먼저 물어본다 | 없음 |
| 연간 요금제(290,000원) 고객이 남은 기간에 대한 환불을 요구 | 부분 환불 가능 여부를 상담원이 판단하지 않음 | 법무 담당자 ([TBD]) + 예외 승인자 |
| 미성년자 결제로 보이거나 명의 도용 주장 | 추가 안내 없이 즉시 넘김 | 법무 담당자 ([TBD]) |
| 예외 승인자가 [TBD: 판단 기한] 안에 결정하지 않음 | 고객에게 지연 안내 후 상위자에게 넘김 | [TBD: CS팀 상위 책임자] |

## 6. 전달 전 품질 체크
- [ ] 결제일, 경과 일수, 요금제, 수강 진도(%)가 티켓에 모두 적혀 있다.
- [ ] 예외 표와 대조한 결과가 적혀 있다.
- [ ] 고객 답변에 사용한 문구가 법무 승인본(또는 승인된 임시 문구)이다.
- [ ] 답변에 상담원이 직접 찾은 법 조항 번호나 법 해석이 들어 있지 않다.
- [ ] 결과 필드와 사유 태그가 선택되어 있다.

### 이 SOP를 완성하려면 필요한 것 (중요한 순서)
1. **법무 검토:** 14일 경과 후 환불 거절이 가능한지, 연간 요금제 부분 환불 의무가 있는지, 고객에게 안내할 조항과 문구가 무엇인지 법무가 정해 주셔야 합니다. 이 결과가 6단계와 예외 표의 법무 관련 줄에 들어갑니다.
2. **예외 승인 기준:** 14일이 지났어도 예외 환불을 해 주는 경우가 있는지, 있다면 누가 어떤 기준으로 승인하는지 알려주세요.
3. **도구 이름:** 티켓 시스템, 결제 관리 시스템, 강의 관리자 페이지의 실제 이름을 알려주시면 [TBD]를 채우겠습니다.
