## 1. 지금 필요한 것 (필수)

**고객 의견 200개 원문** — 아래 중 편한 형태로 붙여 주세요.
- 스프레드시트/CSV 내용 복사, 또는 텍스트 목록 그대로
- 한 줄에 의견 하나면 충분합니다

**있으면 이탈 영향 판단이 훨씬 정확해지는 항목 (선택)**
| 항목 | 왜 필요한가 |
|---|---|
| 고객 ID 또는 계정명 | 같은 고객의 중복 의견 구분 |
| 요금제/매출 규모 | 큰 고객의 불만이 이탈 손실에 더 큼 |
| 해지 여부 / 해지 요청·다운그레이드 표시 | "실제 이탈과 연결된 테마"를 직접 확인 |
| 채널 (전화, 채팅, 이메일, 앱 리뷰 등) | 채널별 편향 보정 |
| 날짜 | 이번 달 안에서 급증한 이슈 식별 |

이 중 하나도 없으면 원문만으로 진행하고, 이탈 영향은 **의견 문구의 신호(해지 언급, 경쟁사 언급, 반복 불만, 업무 차단 여부)**로 추정하겠습니다. 그 경우 결과에 "추정"이라고 명시합니다.

## 2. 받으면 이렇게 정리해 드립니다

**이탈 영향 순위 기준 (가정)**
1. **이탈 신호 강도** — "해지할게요", "다른 서비스로 옮길까", 환불 요청 등 직접 언급
2. **업무 차단 정도** — 핵심 기능이 안 돼서 일을 못 하는가 vs. 불편한 수준인가
3. **빈도** — 200개 중 몇 건, 몇 명의 고객인가
4. **고객 가치** — 데이터가 있으면 고가치 고객 비중 반영

**결과물 형태 (회의용)**
- 테마 목록: 테마명 / 건수·비율 / 대표 고객 발언 2~3개 / 이탈 영향 등급(상·중·하) / 근거
- 이탈 영향 순 Top 3~5 요약 한 장
- 테마별 권장 조치와 담당 팀 제안
- 한계와 가정 (표본 편향, 중복, 추정 부분)

## 3. 미리 알아두실 리스크

- **CS 의견은 불만 쪽으로 치우쳐 있습니다.** 조용히 떠나는 고객은 CS에 연락하지 않는 경우가 많아서, 이 데이터만으로 이탈 원인 전체를 설명하진 못합니다. 회의에서 이 점을 한 줄 언급하시길 권합니다.
- **건수가 많다고 가장 심각한 건 아닙니다.** 예: 사소한 UI 불만 40건보다 결제 오류 8건이 이탈에 더 클 수 있습니다. 그래서 빈도와 심각도를 분리해서 보여드리겠습니다.
- **200개 한 번에 붙이기 어려우면** 나눠서 보내셔도 됩니다. 마지막에 "끝"이라고 알려주시면 합쳐서 분석합니다.
