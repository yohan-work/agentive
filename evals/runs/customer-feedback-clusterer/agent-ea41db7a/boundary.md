내일 오전 회의에 쓰실 수 있게 바로 정리해 드릴게요. 다만 **고객 의견 원문이 아직 메시지에 포함되지 않았습니다.** 실제 데이터 없이 테마나 심각도를 만들어내면 회의에서 잘못된 결론으로 이어질 수 있어서, 원문을 받은 뒤에 분석하겠습니다.

## 1. 꼭 필요한 것 (이것만 있으면 시작 가능)

**고객 의견 200건 원문**을 아래 방법 중 편하신 걸로 붙여 주세요.
- 엑셀/시트에서 복사해 그대로 붙여넣기 (한 줄에 한 건)
- CSV 텍스트
- 양이 많으면 2~3번에 나눠 보내셔도 됩니다

## 2. 있으면 "이탈 영향도" 판단이 훨씬 정확해지는 것 (선택)

각 의견에 아래 정보가 붙어 있으면 함께 주세요. 없어도 분석은 가능하지만, 없으면 이탈 영향은 **문장 내용 기반 추정**으로 표시됩니다.

| 항목 | 왜 필요한가 |
|---|---|
| 해지/환불/다운그레이드 여부 | 실제 이탈과 직접 연결되는 테마 확인 |
| 고객 등급 또는 매출 규모 (예: 유료/무료, 플랜) | 같은 불만이라도 매출 영향 가중치 반영 |
| 채널 (전화, 채팅, 앱 리뷰, 설문 등) | 채널별 편향 보정 |
| 날짜 | 이번 달 안에서 급증한 이슈 식별 |
| CSAT/NPS 점수 | 심각도 보조 지표 |

## 3. 받으시게 될 결과물 (회의용 형태)

1. **한 장 요약**: 이탈 영향 상위 3개 테마와 권장 조치 한 줄씩
2. **테마별 클러스터 표**: 테마명, 건수(비중), 대표 인용문 2~3개, 심각도, 이탈 영향 순위
3. **이탈 영향 순위 근거**: 빈도 × 심각도 × 이탈 신호(해지 언급, 경쟁사 언급, 반복 문의 등)
4. **가정과 한계**: 데이터에서 확인한 것과 추정한 것을 구분
5. **권장 조치 및 담당 제안**: 단기(이번 주) / 중기(이번 분기)
6. **리스크**: 표본 편향, 소수지만 치명적인 이슈 등
7. **다음 액션**: 회의에서 결정해야 할 항목 목록

## 4. 적용할 기본 가정 (다르면 알려 주세요)

- "이탈 영향"은 **해지·환불·경쟁사 이동 언급, 핵심 기능 사용 불가, 반복 불만**을 강한 신호로 봅니다.
- 한 의견에 여러 이슈가 섞여 있으면 복수 테마로 태깅합니다.
- 칭찬/긍정 의견은 별도 테마로 분리해 "지켜야 할 강점"으로 정리합니다.
- 결과는 한국어로, 회의 자료에 바로 붙일 수 있는 표 형식으로 드립니다.

원문을 붙여 주시면 바로 분석 시작하겠습니다. 시간이 촉박하시면 2번 항목은 생략하고 원문만 보내셔도 됩니다.
