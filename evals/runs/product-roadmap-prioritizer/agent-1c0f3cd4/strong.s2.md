## 0. 경영진 요약 (1분 버전)

- **이번 분기 확정 10개 항목, 43pw (가용 60pw의 72%)**, 스트레치 2개 4pw, 나머지 약 13pw는 버퍼입니다. POS 파트너 일정은 우리가 통제할 수 없고 12월 성수기에는 운영 부하도 늘어서, 버퍼를 일부러 크게 잡았습니다.
- **반드시 할 일 (Gate)**: 포스플러스 API v2 마이그레이션(유료 매장 41%, 약 508곳의 연동이 12/31에 끊김)과 모니터링 정비(장애 감지 47분)는 점수와 관계없이 먼저 넣습니다.
- **이탈 목표**: 결제 실패 더닝, 앱 성능 개선, 발주 추천(해지 사유 1위)에 집중합니다. 다만 **발주 추천은 12월 초에야 전체 공개되기 때문에, Q4 말 이탈률은 2.3%까지 가기 어렵고 2.6~2.8%로 보는 게 현실적입니다.** 2.3%는 2027 Q1 목표로 옮기고, Q4는 선행지표로 평가하자고 제안합니다.
- **전환 목표**: 온보딩 체크리스트 개편과 엑셀 업로드 개선을 10월에 먼저 내보내서, 11~12월 체험 코호트에서 효과를 측정합니다.
- **이번 분기에 뺄 것**: 거래처 포털(CEO), 원가 리포트(영업), 다크 모드, 영문 UI, 리퍼럴, 권한 관리. 알림톡(CS)은 스트레치로 둡니다.
- **경영진 결정이 필요한 3가지**: ① 제외 목록 승인, ② 이탈률 2.3% 달성 시점을 Q1로 조정, ③ 11/30부터 신규 기능 배포 동결(기능 플래그로 단계 공개하는 것만 예외).

## 1. 점수 기준

**점수 = 목표 영향 × 신뢰도 ÷ 공수(pw)**

| 요소 | 정의 |
|---|---|
| 목표 영향 | 목표별 기여를 0~3으로 매기고 목표 우선순위대로 가중합: **이탈 ×3 + 전환 ×2 + 안정화 ×1** (최대 18) |
| 신뢰도 | 1.0 = 측정된 행동·운영 데이터 / 0.8 = 설문·인터뷰·추정치 / 0.5 = 요청·주장만 있음 / 0.3 = 데이터 없음 |
| 공수 | 팀장 추정치 그대로 (검증 전) |
| Gate | 외부 마감이 있거나 목표 3(안정화)의 전제 조건이면 점수와 관계없이 포함 |

**점수표를 읽을 때 주의할 점**
- 공수가 작은 항목은 점수가 부풀려집니다. 예를 들어 15번 알림 설정은 근거가 없는데도 0.90이 나옵니다. 그래서 점수는 순서를 잡는 도구로만 쓰고, 최종 결정은 목표 기여와 의존성을 함께 보고 내렸습니다.
- 반대로 발주 추천(2번)처럼 큰 항목은 점수가 낮게 나오지만, 이탈 사유 1위를 직접 해결하는 유일한 항목이라서 포함했습니다.

- **더닝 (9)**: 비자발적 이탈 0.6%p는 월 약 7곳입니다. 업계에서 흔한 회수율 30~50%를 적용하면 **월 -0.2~0.3%p**로, 필요한 감소폭(-0.8%p)의 약 1/3을 2pw로 얻습니다.

- **엑셀 업로드 (5)**: 품목 20개 등록을 가장 빠르게 끝내는 경로라서 온보딩의 사실상 전제 조건입니다. CS 문의 월 38건도 줄어듭니다.
- **다지점 (6)**: 로고 이탈 기준으로는 4곳(0.3%)뿐이라 점수가 낮습니다. 하지만 **매출로 보면 23곳이 14%(약 1,220만 원/월)이고, "없으면 해지"라고 한 4곳은 평균치로 가정하면 MRR 약 210만 원**입니다. 그래서 9pw 전체 대신, 4곳이 실제로 요구하는 최소 범위(예: 지점별 재고·발주 현황 통합 조회, 읽기 전용)를 4pw로 줄이는 조건부 포함을 제안합니다.

## 5. 이해관계자별 설명

### CEO: 14 거래처 포털 제외
- 12pw는 가용 capacity의 20%입니다. POS v2와 이탈 목표를 함께 하면서 넣을 수 없는 크기입니다.
- Q4 목표 세 가지 중 어디에도 직접 연결되지 않고, 검증 데이터도 아직 없습니다.
- **대안**: Q4에는 개발 없이 PM이 디스커버리를 진행합니다(매장 5곳, 공급업체 5곳 인터뷰). 발주 추천으로 매장이 앱 안에서 발주하는 데이터가 쌓이면 포털의 가치를 판단할 근거가 생깁니다. **1월 로드맵 리뷰에서 데이터를 가지고 결정**하자고 제안합니다.

### 영업총괄: 10 원가 리포트 제외 (조건부 재검토)
- 근거가 파이프라인 6건뿐입니다. 평균 ARPU를 적용하면 6건 모두 계약해도 MRR 약 42만 원입니다. 비교하자면 다지점 해지 위험 4곳은 약 210만 원, POS 연동 중단 위험은 수백만 원 규모입니다.
- **재검토 조건**: 6건 각각의 예상 MRR, 단계, "원가 리포트가 유일한 계약 장애물인지"를 10/10까지 받습니다. 합계가 크거나 다지점·대형 고객이 섞여 있으면 Q1 1순위로 올립니다.
- **단기 대안**: 해당 딜에는 원가 데이터 내보내기와 엑셀 템플릿으로 대응하고, 로드맵에 포함된 Q1 후보라고 고객에게 안내합니다.

### CS팀장: 5 포함, 7 스트레치
- **5 엑셀 업로드는 10월에 배포합니다.** 월 38건의 문의가 줄어들 것으로 기대하고 11월에 측정합니다.
- **7 알림톡**은 "요청이 많다"는 것 외에 수치가 없어서 신뢰도 0.5를 줬습니다. 10월부터 CS 티켓에 태그를 붙여 요청 건수를 세 주시면, 스트레치나 Q1 우선순위를 정할 근거가 됩니다. 발주 추천이 나온 다음에 붙이면 효과도 더 큽니다.

### 기타 제외 항목 (공통 근거)
- **8 다크 모드**(요청 11건), **13 영문 UI**(월 2~3건): Q4 목표에 기여하지 않습니다.
- **18 리퍼럴**: NPS 41이면 해볼 만하지만, 신규 획득은 Q4 목표가 아니고 12월 성수기와 겹칩니다. Q1 후보로 둡니다.
- **11 권한 관리**: 보안 문의 월 5건입니다. 해지나 계약 실패와 연결된 사례가 있는지 CS가 확인하면 Q1에 재평가합니다.

## 9. 가정 (틀리면 알려주세요)

1. 매장당 평균 MRR은 약 7만 원(8,700만 ÷ 1,240)이고, 다지점·영업 딜 금액도 평균치로 추정했습니다. 실제 금액을 받으면 5장의 비교를 다시 계산하겠습니다.
2. "10월 말 v2 전환"은 v2가 10월 말에 공개된다는 뜻으로 해석했습니다. v1은 12/31까지 병행 운영된다고 가정했습니다.
3. 60pw에는 디자이너가 포함되어 있고, 휴가 2주가 아직 빠지지 않았다고 봤습니다. 실제 가용량은 약 58.5pw이며 버퍼에서 흡수합니다.
4. 더닝 회수율 30~50%는 업계 일반치입니다. 우리 데이터로 확인되지 않았습니다.
5. 1일차 품목 20개 등록과 전환의 관계는 상관관계입니다. 22% 달성 경로는 이것이 인과라는 가정 위에 있습니다.
6. 다지점 축소판(4pw)은 제가 제안하는 범위이고, 팀장 추정이 아닙니다. 10/16 고객 확인 후에 확정합니다.
